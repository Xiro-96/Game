# ASCENT — Der Turm

Mobile action RPG in the spirit of a Clash-style tower climb: pick a hero, choose a path, fight floor by floor with a three-person squad.

## Play

```bash
npm install
npm run dev
```

Open the shown URL on desktop or phone. Landscape works best.

### Controls

- **Left joystick** / **WASD** — move
- **Light (J)** — combo attacks, charges Heavy
- **Heavy (K)** — hold and release in the green window for a Perfect
- **Skill (L)** — unique hero ability
- **Esc** — pause

## Loop

1. Camp hub
2. Hero select (6 kits)
3. Path: Brave (5) / Heroic (10) / Legendary (15)
4. Combat, elite, survival, and boss floors
5. Pick a perk after each floor
6. Gold and unlocks persist in localStorage
