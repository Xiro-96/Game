# ASCENT — Handyspiel

Turmsteigen im Querformat. Touch only: Joystick links, Angriffe rechts.

## Auf dem Handy starten

1. Im Projektordner:

```bash
npm install
npm run dev
```

2. Im Terminal steht eine **Network**-Adresse, z.B. `http://192.168.0.23:5173`
3. Handy und Rechner ins **gleiche WLAN**
4. Diese Adresse im **Handy-Browser** öffnen (Safari oder Chrome)
5. Handy **quer** halten
6. Wie eine App installieren:
   - **iPhone:** Teilen → Zum Home-Bildschirm
   - **Android:** Menü ⋮ → App installieren / Zum Startbildschirm hinzufügen

Danach öffnest du nur noch das Icon. Kein Browser, keine Tastatur.

`localhost` / `127.0.0.1` auf dem Handy funktioniert nicht — immer die Network-IP aus dem Terminal nutzen.

## Steuerung

- **Linker Daumen:** Joystick
- **Rechter Daumen:** Leicht · Schwer (halten für Perfect) · Skill
